# 学习与思考

这是 YangHanLin 的个人博客与学习笔记知识库，用于记录技术实践、整理学习路径，并把零散知识沉淀为可以持续回顾的内容。

访问网站：[https://tangsong777.github.io](https://tangsong777.github.io)

## 内容组成

- **文章**：个人技术实践、经验总结与思考，按照博客时间线和归档页展示。
- **学习笔记**：从思源笔记整理而来的知识库，保留文档目录、页内定位和文档间引用关系。

## 技术实现

网站基于 Hexo 与 NexT.Muse 主题构建，使用 GitHub Actions 自动生成并发布到 GitHub Pages。项目另外包含思源笔记转换工具和仅在本地运行的 Markdown 文章工作台。

## 关于内容与 AI 协作

本项目由本人在 Codex 协助下进行网站功能开发、界面调整和自动化工具维护。

部分学习笔记在整理、归纳和辅助学习过程中使用了 AI 模型，内容仅代表阶段性的学习记录，可能存在疏漏，请结合可靠资料自行验证。

网站中的正式文章均由本人独立构思和编写，文中观点、表达与最终内容由本人负责。AI 不作为文章作者。
