MARKDOWN GUIDE
Markdown 语法速查

      
    

    

      
所见即所得：输入即转换
在新段落开头输入前缀并按半角空格：# 到 ######、>、- / + / *、1.、*** / --- / ___。待办先输入 - ，再输入 [ ]  或 [x] 。
粗体、斜体、删除线、行内代码、链接在输入闭合符号后转换；代码块输入 ```js 或 ~~~js 后按回车或空格。支持 Ctrl+Z；代码块内不触发这些规则。
列表嵌套使用工具栏缩进按钮；图片使用图片按钮、粘贴或拖入；表格使用表格按钮。完整 Markdown 表格、HTML、摘要分界、复杂链接及转义内容可在源码模式编辑；下方语法示例不代表所有内容都会实时转换。需要软换行时，在所见即所得模式按 Shift+Enter。
