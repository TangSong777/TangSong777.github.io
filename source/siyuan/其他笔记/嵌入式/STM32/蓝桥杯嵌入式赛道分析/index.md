> 基于本笔记本沉淀的资料与历年真题，对蓝桥杯嵌入式赛道进行考点归纳与备赛分析。原始真题记录见子文档：历届省赛真题模块使用、历届国赛真题模块使用。

## 一、赛道考察范围概览

蓝桥杯嵌入式赛道围绕 STM32 统一开发板考察嵌入式编程能力，题型以"外设驱动 + 业务逻辑"组合为主：

- **省赛**：以外设模块组合为核心（LED / LCD / KEY 为必考底座，叠加定时器、ADC、串口等）
- **国赛**：在省赛基础上加深，更考验代码功底（15 届国赛出现数据结构进阶）

## 二、模块考频归纳

### 2.1 必考（历届都有）

- **LED**：指示界面/运行状态，可能要求闪烁
- **LCD**：三个界面（数据界面 / 参数界面 / 记录界面），用 B4 短按或长按切换界面
- **KEY**：短按 / 长按区分（时长阈值），作为界面切换与参数调整入口

### 2.2 高频

- **定时器输入捕获**：测频率（14 届）、双通道捕获（15 届）
- **定时器 PWM 输出**：指定频率与占空比，14 届要求步进值 < 200Hz
- **ADC 采集**：读取电压（14 届有要求，15 届无）
- **串口 UART**：数据收发与指令解析

### 2.3 进阶模块（按题目需要出现）

- **EEPROM / IIC**：参数掉电保存、IIC 设备挂载
- **旋转编码器 / 编码电机**：TIM 编码器模式计数（详见旋转编码器与电机详解）

### 2.4 国赛特点

- 更强调 C 语言功底：15 届国赛出现**双向链表、双指针、添加/删除 Node** 等数据结构操作

## 三、省赛真题要点

### 3.1 第十四届

- LCD：三个界面
- LED：指示界面状态，可能要求闪烁
- 按键：区分长按和短按
- 定时器输入捕获：频率测量
- 定时器 PWM 输出：指定频率和占空比，步进值 < 200Hz
- ADC：使用 ADC 获取电压

### 3.2 第十五届

- LCD：三个界面
- LED：指示界面状态或提示频率大小
- 按键：仅要求短按
- 定时器输入捕获：双通道捕获
- ADC：无要求

## 四、国赛真题要点

### 4.1 第十五届

- 数据结构进阶：双向链表、双指针、添加删除 Node

## 五、备赛策略建议

1. 打牢必考三件套：LED、LCD（三界面框架 + B4 切换）、KEY（长短按状态机）——参照《知识点大纲》一～三章
2. 掌握定时器三件套：输入捕获（频率/占空比）、PWM 输出、编码器计数——参照《知识点大纲》六～七章 + 旋转编码器与电机详解
3. 补齐数据通道：ADC（DMA 采集）、UART（DMA/空闲中断接收）——参照《知识点大纲》四～五章
4. **进阶准备**：IIC/EEPROM 读写、参数掉电保存、IIC 扫设备
5. **赛前演练**：以 14/15 届模块组合做模拟题，重点练"LCD 三界面切换 + 按键参数调整"工程框架
6. **国赛方向**：补强 C 数据结构（链表、双指针、内存管理）
