# 我的 Skill 体系速查手册

>> 本手册用于快速查阅我创建的 10 个 Skill 及其功能、触发时机与彼此关系。**所有 Skill 按名称首字母 a-z 排序。最后更新：2026-08-24（note-organize 固化归档默认方式：移入已归档+改名，不再询问用户）。**  手册仅记录当前状态。
>>

## 一、场景 → 用哪个 Skill（速查）

- ① ability-summary —— 能力体系总结
- ② decision-point —— 需求澄清与方向确认（模糊需求/多方案时先问）
- ③ document-refactor —— 净化重构（未覆盖 → 调④补齐）
- ④ knowledge-coach —— 模式A：文档内二次笔记迭代补齐 / 模式B：跨文档定位补充新知识点
- ⑤ learning-plan-generator —— 生成学习方案（能力同步+答案伴随）
- ⑥ leetcode-organizer —— 力扣每日整理
- ⑦ link-checker —— 引用校验（旁路）
- ⑧ note-organize —— 整理笔记（提炼而不精简）
- ⑨ session-state-sync —— 会话状态手册同步（旁路）
- ⑩ skill-manual-updater —— Skill 手册同步 + 重复校验（旁路）

## 三、各 Skill 详细介绍

### 1. ability-summary —— 能力体系总结

- **功能**：每次笔记整理/学习完成后，总结已掌握知识点与证据，按 **A/B/C 三类**更新《能力评估》（A 等级制 / B 混合 / C 确认制）与《能力规划》（规划项标注类别、与评估机制对齐）。
- **等级标准**：五层 L0-L5 用于 A 类与 B 类等级制项——L0 不了解 → L1 知道概念 → **L2 必须依托笔记/AI 才能进行** → **L3 可以简单脱离笔记/AI 进行一定操作** → L4 高频独立实践做得好 → L5 创新/指导；B 类确认制项与 C 类只维护 `✓ 确认/未确认`，不评等级。
- **维护规则**：能力评估按 A/B/C 组织、只记当前状态；能力规划标注 A/B/C；确认制项完成笔记即 ✓（未确认→完成笔记确认→✓）；原理/工具能力进入工程实践后经用户确认可升 A 类路径；L2→L3 需"脱离资料成功完成一次常见任务"的证据；默认本人确认制。

### 2. decision-point —— 需求澄清与方向确认

- **功能**：你提出需求后若方向不明确、需求模糊、多方案分叉、或涉及大规模/破坏性修改时，我**先用 Question 工具**给出结构化选项（每个选项带影响说明，含自定义入口）向你确认"是不是该这么做、该怎么做"，确认后再执行，避免猜测返工。
- **原则**：先复述需求理解再提问；一次问到位（1-3 问）；不过度提问（能合理推断的默认执行）；重大操作即使明确也先确认。

### 3. document-refactor —— 文档重构与净化

- **功能**：当我觉得文档有结构性错误、需要整理内容、或知识补充迭代完成后，校验文档中残留的"二次笔记"是否已被正式讲解覆盖；**未满足 → 调 knowledge-coach（④）补齐；已满足 → 重构文档并删除二次笔记**，让知识点笔记保持"纯净知识点"状态（不含疑问/需求等过程性内容）。
- **流程**：收集二次笔记清单 → 逐条校验覆盖 → 缺失则补齐 → 删除二次笔记（心得提炼入附录）→ 重排编号/清理空块 → link-checker 校验 → 输出重构报告。
- **边界**：删除二次笔记前必须确认已被正文覆盖，宁可保留不可丢失意图。

### 4. knowledge-coach —— 知识补充与迭代教练

- **功能**：两模式合一——模式A：我对学习方案/已整理笔记做二次笔记或提问时，把疑问/心得转为讲解补进原文（保留原始笔记）；模式B：我要求"补充一个知识点"时，自动定位合适文档与章节、按既有风格插入。
- **工作方式**：A：归类→生成讲解→插入→保留笔记→记录→验证题；B：提取主题→检索定位文档章节→去重→按风格插入→说明放置理由。
- **原则**：讲解格式对齐 learning-plan-generator（定义→类比→细节→易错→验证）；问题驱动、层层加深；整体结构重排走 document-refactor / note-organize。

### 5. learning-plan-generator —— 学习方案生成

- **功能**：围绕未知知识点生成系统化学习方案文档。核心是"每个知识点讲透"，不是泛泛的目标清单。**生成前先做能力体系同步校验**：该能力是否已登记，无则新增、有则更新（能力评估/规划）。
- **输出样式**（对齐《博客网站部署学习方案》）：引言声明教学讲义性质；章节按依赖排序；能力基线表 + 暂不学习清单 + 里程碑；每章一句话定义 + 逐知识点详解（**定义→类比/图示→命令逐行→易错点→验证**）；学习阶梯；三类证据要求；**答案伴随原则**——所有自测题/遗留问题必附标准答案，无答案的问题不保留。
- **产出位置**：学习方案文档创建在「学习笔记」笔记本的「待学习」文档下作为子文档（`/待学习/<方案名>`​），可附带执行 Prompt 子文档；学习完成归档时移入「已归档」文档下（`/已归档/<方案名>（已归档）`）。

### 6. leetcode-organizer —— 每日力扣刷题整理

- **功能**：把每天日记中的力扣题解（题目/解题法/小笔记）整理进「力扣刷题」体系（时间线索引 + 类型索引），并把可复用知识点归纳进《Python笔记/算法专项》。
- **整理要求**：时间线/类型索引条目结构固定（H3 题目 + 官网链接 + 原笔记双括号引用）；算法专项沿用现有分类体系（遍历/列表/字符串/链表/双指针/哈希/位运算/矩阵/内置函数/算法思想/数学技巧），同知识点合并，每条知识点标注来源题目原块引用（`来源：((日记题解块ID "题号.题名"))`）；保留日记原文不修改。

### 7. link-checker —— 引用规范校验（默认旁路）

- **功能**：扫描全库，确保所有文档/块引用采用思源双括号 `((块ID "标题"))`​，禁止 `[text](siyuan://blocks/ID)`​、裸 `siyuan://`​ URL、`[[ID]]` 式引用；同时做断链检测。
- **执行时机**：每次文档内容增添/删改后自动执行（默认旁路），也可应要求全库扫描。
- **实现**：SQL 扫描 blocks 表定位违规 → 校验目标块 ID 真实性 → 替换为双括号 → 复查清零 → 输出校验报告。
- **注意**：代码块中的 `[[1,2,3]]` 是合法代码不修改；修改列表块用子项级更新避免结构损坏。

### 8. note-organize —— 笔记整理

- **功能**：学习完成后按知识链条整理成可复用、结构逻辑完整的规范知识笔记；核心原则"提炼而不精简"，只删过程性流水账；**学习文档存于「待学习」下，归档移入「已归档」下（均为子文档，重命名加"（已归档）"）——归档默认采用"document.move 到 /已归档 + rename 加后缀"，不再询问用户**；**归档动作完成后，先用 Question 工具询问是否需要整理知识点笔记，确认后再执行整理流程**；用户遗留的"笔记："块须转化为带答案讲解并入正文（答案伴随原则）。
- **规范要点**：文档三分离（知识笔记/能力评估/能力规划）；知识链条优先；每章一句话定义 + 独立编号；表格用于对比/速查/选型；个人心得入附录；常见问答校正后纳入（含澄清讲解）；引用一律双括号 `((块ID "标题"))`。
- **流程**：读取 → 提取 → 校正问答 → 重建链条 → 重写正文 → 触发 ability-summary → 清理 → 校验（配合 link-checker）。

### 9. session-state-sync —— 会话状态恢复手册同步（默认旁路）

- **功能**：每当知识库发生重要变更（文档新增/删除/重命名/移动、Skill 变更、能力评估/规划更新、学习方案创建与归档、目录重建）后，**自动同步《会话状态恢复手册》** （结构总览、Skill 列表、ID 速查、待办状态、最后更新日期），确保任何新会话都能无缝续接。
- **触发**：默认旁路；轻量编辑可累计到会话关键节点统一同步。
- **分工**：本 skill 管「会话手册」整体状态；skill-manual-updater 管「Skill 速查手册」细节（a-z 排序/重复校验）。

### 10. skill-manual-updater —— Skill 速查手册同步更新（默认旁路）

- **功能**：每次创建/修改/删除/重命名 Skill 后，立即同步更新本手册（一览/总览、详细介绍、工作流闭环、场景速查），**所有 Skill 列表按名称首字母 a-z 排序**，并校验 Skill 间功能重叠，发现明显重叠时向你提出合并/保留申请。
- **流程**：skill list → 重复校验 → 按 a-z 重排 → 重建各部分 → 校验 → 汇报变更摘要与重叠结论。

## 四、工作流闭环

```
遇到未知知识点
   ↓
① learning-plan-generator → 生成教学讲义学习方案
   ↓
按方案学习（边学边留证据、写心得）
   ↓ 有二次笔记/提问/要补充知识点？
④ knowledge-coach → 迭代补齐讲解 / 定位补充新知识点
   ↓ 二次笔记已覆盖？
③ document-refactor → 校验覆盖 → 净化删除二次笔记（可选）
   ↓ 学习完成
⑧ note-organize → 整理成知识笔记（归档学习文档）
   ↓
① ability-summary → 更新能力评估与能力规划
   ↓
形成新能力，进入下一轮学习

全程旁路：
- ⑦ link-checker：每次文档增删改后校验引用规范
- ⑩ skill-manual-updater：Skill 变更后同步 Skill 手册（a-z）
- ⑨ session-state-sync：重要变更后同步会话恢复手册
- ⑥ leetcode-organizer：力扣每日整理
```
