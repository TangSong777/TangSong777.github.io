> 本文档只记录后续能力规划、待学习内容、知识缺口、优先级和项目连接，不记录当前能力评估结果或历史等级变化。

## 一、规划原则

> 学习路线围绕“一指知心”项目的实际瓶颈展开，优先补齐能够直接支撑实验的知识。

- 先补项目直接卡脖子的基础，再扩展中期工具和部署能力。
- 每项规划包含：知识缺口、学习内容、最小实践和完成目标。
- 文档中的 L0→L2、L2→L3 仅表示规划目标，不替代《能力评估》中的当前等级。
- 能力等级变化只更新《能力评估》，不在本文档维护。

- **分类对齐**：规划项按能力评估的 A/B/C 机制标注——A 类（等级制，优先补"一指知心"卡脖子项）；B 类（混合：确认制项仅"完成笔记确认"，等级制项照常规划）；C 类（确认制，不深入规划，完成后只做 ✓ 确认）。

## 二、P0：项目直接卡脖子

### 2.1 Python 文件操作（已完成 → L2，深化至 L3 候选）

**已完成**：实验数据目录管理、批量读取与路径解析已系统学习并归档，知识沉淀为 [PathLib专项](/siyuan/Python笔记/PathLib专项/)（含路径基础、拼接陷阱、遍历筛选、CSV 读写、批量处理综合案例、高级文件操作），能力评估更新为 L2。

### 2.2 OpenCV 基础（目标：L2，学习方案已生成 2026-08-27）

**知识缺口**：尚未形成视频帧处理和指端 ROI 提取能力。

|学习内容|项目用途|
| ---------------------| ----------------|
|`imread`​、`imshow`​、`imwrite`|读取和保存图像|
|BGR、RGB、灰度、HSV|统一颜色格式|
|图像矩阵与 ROI 切片|裁剪指端区域|
|缩放、翻转、平移|ROI 对齐与增强|
|阈值、mask、`bitwise_and`|隔离指端区域|

**最小实践**：读取指端图像，完成灰度化、二值化、mask 生成和 ROI 提取。

### 2.3 PyTorch 与 CNN 基础（目标：L2，学习方案已生成 2026-08-27）

**知识缺口**：尚未独立跑通模型训练、验证和评估闭环。

|学习内容|项目用途|
| -----------------------------| ------------------------|
|Tensor、Dataset、DataLoader|构造信号窗口和 batch|
|卷积、池化、全连接|提取空间特征|
|loss、optimizer、训练循环|模型拟合|
|train/val 划分、checkpoint|防止数据泄漏并保存模型|

**最小实践**：在合成波形数据上跑通一个 CNN 训练闭环，并理解 loss 曲线和 train/val 差异。

### 2.4 数据结构与算法（C/C++ 嵌入式）（目标：L2，学习方案已生成 2026-08-27）

**知识缺口**：嵌入式代码中链表/队列/树/图、enum/typedef struct 的组织能力不足。

|学习内容|项目用途|
| ---------------| ------------------|
|`enum`​/`typedef struct`|状态机与数据打包|
|指针与数组|串口缓冲|
|队列/环形缓冲|任务与事件队列|
|链表/树/图|菜单、决策、路径|

**最小实践**：用 C 实现"事件入队→switch 分发"骨架 + 一个动态菜单链表。

### 2.5 控制算法（PID）（目标：L2，专项文档已生成 2026-08-27）

**知识缺口**：闭环控制无经验，无法让风扇立棍站稳、小车走直线。

|学习内容|项目用途|
| ------------------------| -----------------|
|P/I/D 三环节与离散公式|闭环控制基础|
|位置式/增量式模板|可移植 PID 代码|
|风扇立棍（角度/双环）|自平衡类控制|
|小车轮速环+循迹差速|走直线/循迹|

**最小实践**：STM32 定时器驱动 PID，先让一个轮速闭环（编码器），再做循迹差速。

## 三、P1：短期需要

### 3.1 NumPy 进阶与 SciPy 信号处理（目标：L3）

**知识缺口**：需要把基础数组操作提升为可独立使用的信号预处理能力。

|学习内容|项目用途|
| ------------------------| ------------------------------|
|多维索引、切片、广播|ROI 像素和批量信号处理|
|`rfft`​、`rfftfreq`|PPG 频域分析与心率提取|
|幅度谱归一化 `2/N`|恢复信号幅值|
|频谱泄露、奈奎斯特采样|采样率与频率分辨率设计|
|`butter`​、`cheby1`​、`iirnotch`|去除漂移、运动伪影和工频干扰|
|`lfilter`​ 与 `filtfilt`|比较实时滤波与离线零相位滤波|

**最小实践**：独立完成“合成含噪信号 → FFT 分析 → 低通/陷波滤波 → 对比滤波结果”的预处理 pipeline。

### 3.2 PPG 与 rPPG（B 类·确认制，当前未确认）

**知识缺口（B 类确认制，当前未确认）** ：按能力评估分类，PPG/rPPG 属 B 类"仅需基本了解"（原理层），当前状态为**未确认**——先完成原理学习并通过笔记确认（✓），再谈工程实现；一旦进入"视频到 ROI 到信号"最小闭环（工程实践），可升 A 类等级制路径。

- PPG 与 rPPG 的信号来源和差异
- ROI 选择、颜色通道和信号提取
- 运动伪影、基线漂移和信号质量评价
- 心率、HRV、血管反应性和 MV-RHI 的计算基础

**最小实践**：从视频或模拟数据提取时间序列，完成滤波、频域分析和心率估计。

## 四、P2：中期需要

### 4.1 Linux 与板卡管理

**知识缺口**：需要在 Rock 5B+ 上形成脱离笔记可处理常见问题的实践能力。

- 文件与目录：`ls`​、`cd`​、`cp`​、`mv`​、`rm`
- 权限与安全：`chmod`​、`chown`​、`stat`
- 进程与资源：`ps`​、`pgrep`​、`top`​、`kill`
- 搜索与日志：`grep`​、`find`​、管道、重定向、`tail`
- 后台与服务：`&`​、`nohup`​、`systemctl`

**最小实践**：在板卡上部署一个脚本，后台运行并记录日志，完成进程、权限和错误排查。

### 4.2 SSH（已完成 → L2）

**已完成**：SSH 免密登录、文件传输（scp/rsync）、端口转发（-L/-R）、会话保持（tmux）、常见故障与安全加固已系统学习并归档，知识沉淀为 [SSH专项](/siyuan/其他笔记/命令行/SSH专项/)，能力评估更新为 L2。

|学习内容|项目用途|

|密钥对与 `authorized_keys`|免密登录 Rock 5B+|
|`sshd_config`|登录策略与安全配置|
|`scp`​、`rsync`|实验数据传输|
|端口转发|访问板卡内部服务|
|`tmux`​、`screen`|保持远程任务会话|

### 4.3 Docker（B 类·等级制，学习方案已生成 2026-08-27）

**知识缺口**：尚未建立可复现的实验环境和部署环境。

- 镜像、容器、仓库
- Dockerfile 与 Python/PyTorch 环境
- `build`​、`run`​、`exec`​、`ps`​、`logs`
- 卷挂载、端口映射和 Compose

**最小实践**：编写 Dockerfile 打包一个 Python 训练脚本，运行并挂载数据目录。

### 4.4 深度学习与模型部署

**知识缺口**：需要从基础 CNN 训练逐步过渡到 Rock 5B+ 上的推理部署。

- PyTorch 训练、验证与 checkpoint
- Transformer/Attention 与时序建模
- ONNX 导出与模型检查
- RKNN、量化和 Rock 5B+ 推理
- 速度、内存和精度权衡

### 4.5 Windows 命令行（PowerShell/CMD，已完成 → L2）

**已完成**：PowerShell 与 CMD 基础命令、进程/环境变量、PS-CMD 对照与别名机制、IP 与网络排查均已系统学习并归档（《Windows命令行学习（已归档）》），能力评估更新为 L2。

学习文档：[Windows命令行学习（已归档）](/siyuan/已归档/Windows命令行学习（已归档）/)

- PowerShell：`Get-Location`​、`Get-ChildItem`​、`Set-Location`​、`New-Item`​、`Copy-Item`​、`Move-Item`​、`Remove-Item`​、`Get-Content`​、`Select-String`​、`Get-Process`​、`Stop-Process`
- CMD：`cd`​、`dir`​、`mkdir`​、`copy`​、`move`​、`del`​、`type`​、`findstr`​、`tasklist`​、`taskkill`
- 对比 PowerShell 对象管道与 CMD 文本管道、帮助系统、重定向和环境变量。

**最小实践**：分别使用 PowerShell 和 CMD 完成目录/文件创建、日志搜索、进程查询与结束，并总结命令对应关系。

### Windows IP 与网络命令（已完成，并入 L2 评估）

**已完成**：PowerShell（`Get-NetIPConfiguration`​/`Test-Connection`​/`Test-NetConnection`​/`Resolve-DnsName`​ 等）与 CMD（`ipconfig`​/`ping`​/`nslookup`​/`netstat`​/`route print` 等）的 IP 与网络排查命令已学习并归档，随《Windows命令行学习（已归档）》纳入 Windows 命令行 L2 评估。

学习文档：[Windows命令行学习（已归档）](/siyuan/已归档/Windows命令行学习（已归档）/)

- PowerShell：`Get-NetIPConfiguration`​、`Get-NetIPAddress`​、`Get-NetAdapter`​、`Get-NetRoute`​、`Resolve-DnsName`​、`Test-Connection`​、`Test-NetConnection`​、`Get-NetTCPConnection`
- CMD：`ipconfig /all`​、`ping`​、`nslookup`​、`tracert`​、`pathping`​、`route print`​、`arp -a`​、`netstat -ano`
- 重点理解：本机配置 → 网关连通性 → 公网 IP → DNS 解析 → TCP 端口 → 路由路径的排查顺序。

**最小实践**：分别用 PowerShell 和 CMD 查看本机 IPv4、默认网关、DNS、路由表，测试一个公网地址和一个 TCP 端口，并区分 DNS 问题、网络不通和端口未开放。

### 5.2 简单 PCB 绘制

## 六、暂不学习

- 与当前科研代码关系较弱的集合高级数学运算
- 高级 Transformer、复杂 Edge AI、复杂部署和高级硬件设计，待前置实验闭环完成后再安排
