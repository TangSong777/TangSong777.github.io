## 阶段一：可变与不可变（先建立心智模型）

### Step 1：观察「改」的两种含义

```python
a = 10
b = a
a += 1
print(a, b)          # 11 10

lst = [1, 2, 3]
lst2 = lst
lst.append(4)
print(lst, lst2)     # [1, 2, 3, 4] [1, 2, 3, 4]
```

**理解**：`int`​ 是不可变对象，`a += 1`​ 实际是新建一个对象；`list`​ 是可变对象，`lst.append` 是在原对象上原地修改。

**自己做**：把 `lst2 = lst`​ 改成 `lst2 = lst.copy()`，再运行一次，观察结果变化并解释。

‍

笔记：理解Python的变量本质，当使用`a = 10`​时，是让a这个变量绑定等于10的对象，在后续再次对a进行赋值操作时，例如`a += 1` 其操作流程为：确认a为int类型，确认1为int类型，将a与1返回到CPU加法器中做运算，返回一块内存区域，其值为a+1，让a指向这个区域。所以说不可变是指a指向的这个内存区域，也就是值等于10的这个区域，值不能再修改，只能让a指向其他的内存区域，通过这种方式来“赋值”a。

### Step 2：哪些类型不可变、哪些可变

|类型|是否可变|示例|
| ----------------| ----------| ----------------|
|int/float/bool|不可变|10, 3.14, True|
|str|不可变|"hello"|
|tuple|不可变|(1, 2)|
|list|可变|[1, 2]|
|set|可变|{1, 2}|
|dict|可变|{"a": 1}|

**易错**：`{}`​ 是空字典，空集合要用 `set()`

笔记：已理解

## 阶段二：List（列表）

### Step 3：增删改查

```python
a = [1, 2, 3]
a.append(4)        # [1, 2, 3, 4]
a.insert(1, 99)    # [1, 99, 2, 3, 4]
a.remove(99)       # [1, 2, 3, 4]
x = a.pop(0)       # x=1, a=[2, 3, 4]
```

**理解**：`append`​ 加末尾、`insert(i, x)`​ 在下标 i 前插入、`remove(x)`​ 删第一个匹配值、`pop(i)` 删并返回下标 i 的元素。

**自己做**：对 `[1, 2, 3]`​ 依次执行 `append(4)`​、`pop()`​、`insert(0, 0)`，打印每一步结果。

笔记：已理解

### Step 4：切片与复制

```python
a = [1, 2, 3, 4, 5]
print(a[1:4])       # [2, 3, 4]
print(a[::-1])      # [5, 4, 3, 2, 1]
b = a[:]            # 浅拷贝，等于 a.copy()
```

**易错**：`b = a` 不是复制，两个名字指向同一列表；改一个另一个也变。

笔记：参考数据类型，列表是可变数据类型，而b与a都指向这同一个对象，当对a列表进行append等修改时，b指向的对象发生了改变，所以本质上b与a指向的对象是头一个。

如果需要保留原列表不变对一个新列表去进行修改的话，就可以使用copy方法来新建一个对象，让b指向这个新对象，如此，a保留原列表数据，只需要对b进行修改即可。

## 阶段三：Tuple 与 Set

### Step 5：Tuple 的不可变性

```python
t = (1, 2, 3)
# t[0] = 9   # 报错：tuple 不支持赋值
x, y, z = t    # 拆包
```

**理解**：Tuple 适合表示固定结构（如坐标、RGB 值），可以作为字典键。

笔记：元组类似于C语言中的const或者define，比如说C语言中可能会有

#define Rows 128

#fdefine Columns 64

但元组中常常写screen = (128, 64)

类似的，颜色写法#define TianYiLan #66CCFF

可以用元组和RGB表示为`(102, 204, 255)`

### Step 6：Set 去重与查找

```python
s = {1, 3, 3, 4}
print(s)           # {1, 3, 4}
print(3 in s)      # True
s.add(5)
s.remove(1)
```

**理解**：Set 自动去重、元素唯一，适合快速判断「是否存在」。逻辑上无序，不靠下标访问。

笔记：有时候可以用集合来建立哈希表

## 阶段四：Dict（字典）

### Step 7：键值对的增删改查

```python
d = {"name": "Pig", "age": 20}
d["name"]            # 'Pig'
d["name"] = "Fog"    # 修改
d["city"] = "杭州"    # 新增
del d["age"]         # 删除
```

**理解**：字典用键找值；键必须唯一且不可变。

笔记：非常好用啊，经常建立哈希表，键为num或者字符，值为下标或者出现次数

### Step 8：为什么键必须是不可变类型

```python
d = {}
d[(1, 2)] = "ok"     # tuple 可哈希，可以作为键
# d[[1, 2]] = "no"   # 报错：list 不可哈希
```

**理解**：字典靠键的哈希值定位；可变对象内容会变，哈希值不稳定，所以不能做键。

笔记：为什么键必须是不可变类型，因为键本质存储的是值对应的哈希值，可以简单理解为对象的地址。

对于元组/字符串这种不可变类型，其对象的哈希值是固定的，可以哈希，所以可以作为键。

### 证据 3：口头解释

1. `b = a`​ 和 `b = a.copy()` 的区别？前者的“赋值”操作实际将b与a都指向了同一个对象，如果a是可变数据类型，当对a里的数据进行改动的时候，读取b里的数据，会发现他也改变了。后者本质为新建了一块内存区域，存储了与a一致的数据，但是a不做修改，将b指向这一个新建的内存区域，二者独立。
2. 为什么 `[1, 2]`​ 不能做字典键，而 `(1, 2)` 可以？因为前者是可变数据类型，无法哈希。后者是不可变数据类型，可以哈希作为键。
3. Set 和 List 各自适合什么场景？set是集合，常用于去重等场景。list是列表，常用于表示一维有序的数据集合。
