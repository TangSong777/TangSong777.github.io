# 思源笔记中写 LaTeX 公式

> 思源内置 LaTeX 公式支持，有两种形态：**行内公式**（随文字走，用 ​`$...$`​）与**数学公式块**（独占一行/整块，用 ​`$$...$$`​，是独立的叶子块，可拖动、可被引用）。官方说明见 (( '用户指南：数学公式')) 与 (( '用户指南：数学公式块'))。

## 一、两种形态对比

|形态|怎么写|适用|特点|
| ----------| ---------------------------| --------------------| -----------------------------------|
|行内公式|`$a^2+b^2=c^2$`|句子中的符号、短式|与文字同行，随段落排版|
|公式块|`$$`​ 换行写公式 换行 ​`$$`|独立推导、多行公式|独立块（叶子块），可拖拽/被块引用|

**输入方式**：两种都可直接敲 ​`$`​（敲两下 ​`$$`​ 回车即公式块）；也可输入 ​`/` 打开菜单选「数学公式」。

**效果对照**（左侧为源码写法，右侧为渲染结果）：

|源码|渲染效果|
| ------| ----------|
|`$a^2 + b^2 = c^2$`|$a^2 + b^2 = c^2$|
|`$\frac{a}{b}$`|$\frac{a}{b}$|

## 三、典型示例（可整段复制到公式块）

**示例 1 · 一元二次求根公式**

```latex
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
```

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

**示例 2 · 求和与积分**

```latex
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}, \qquad
\int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
```

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}, \qquad \int_{0}^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

**示例 3 · 多行对齐推导**

```latex
\begin{aligned}
(a+b)^2 &= a^2 + 2ab + b^2 \\
(a-b)^2 &= a^2 - 2ab + b^2
\end{aligned}
```

$$
\begin{aligned} (a+b)^2 &= a^2 + 2ab + b^2 \\ (a-b)^2 &= a^2 - 2ab + b^2 \end{aligned}
$$

**示例 4 · 分段函数与矩阵**

```latex
f(x) = \begin{cases}
x^2, & x \ge 0 \\
-x,  & x < 0
\end{cases}
\qquad
A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}
```

$$
f(x) = \begin{cases} x^2, & x \ge 0 \\ -x, & x < 0 \end{cases} \qquad A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}
$$

**示例 5 · 中文与颜色（工程公式常用）**

```latex
\text{心率} = 60 \times \color{red}{f_{\text{主频}}}
```

$$
\text{心率} = 60 \times \color{red}{f_{\text{主频}}}
$$

## 四、思源里的实用技巧

|技巧|做法|
| ------------------------| -------------------------------------------------------------------------------------|
|块级公式当"块"用|公式块是独立叶子块：可拖动排序、可被引述/引用（块标菜单里操作）|
|公式与文字混排|行内公式直接写在句子里，如"当 $x>0$ 时函数递增"|
|表格里用公式|表格单元格内也能用行内公式（对比数值时很有用）|
|复制给别人|点进公式块可直接取到 LaTeX 源码；导出 Markdown 时公式会以 ​`$`​/​`$$` 形式保留|
|粘贴外部公式|从论文/网页复制的 ​`$...$`​、​`$$...$$`​ 或 ​`\(...\)`​、​`\[...\]` 形式的 LaTeX，多数可直接粘贴渲染|
|导入 Markdown 识别公式|若导入/粘贴时公式没被识别，去 设置 - 编辑器 - **Markdown 语法** 打开相关开关（识别 ​`$foo$` 等扩展语法）|

## 五、易错点

-  **​`$`​** ​ **要成对**：只写一个 ​`$`​ 会吞掉后面的文字；行内公式两端各一个 ​`$`​，公式块两端各 ​`$$`；
- **多字符上下标要加大括号**：​`a^10` 只会渲染成 $a^10$（只有 1 上标），要写 ​`a^{10}` → $a^{10}$；
- **命令拼写与转义**：反斜杠命令写错会直接显示红色报错（如 ​`\frac`​ 写成 ​`\frac{}{`​ 不完整）；​`%`​、​`$`​、​`&`​、​`_`​ 等符号在公式里有特殊含义，普通显示需转义（​`\%`​、​`\$`​、​`\&`​、​`\_`）；
- **中文不进 LaTeX 正文**：直接写中文会报错/不渲染，必须 ​`\text{中文}`；
- **多行必须用环境**：想换行/对齐要用 ​`aligned`​、​`cases` 等环境，不能直接敲回车；
- **行内公式过长会挤压排版**：长式子（如多行推导）改用公式块更清晰；
- **别用中文标点做公式分隔**：​`$`​、​`$$` 必须是英文半角符号。

## 六、自测（附答案）

1. **行内公式与公式块的写法与区别？**  答：行内 ​`$...$`​，随文字排版；公式块 ​`$$...$$`，独占成块（叶子块，可拖动；适合长式/推导）。
2.  **​`\frac{a}{b}`​** ​ **、** ​ **​`\sqrt[3]{x}`​** ​ **、** ​ **​`\sum_{i=1}^{n}`​** ​ **分别渲染成什么？**  答：$\frac{a}{b}$、$\sqrt[3]{x}$、$\sum_{i=1}^{n}$（分别是分数、n 次根、下标起止求和）。
3. **公式里要写中文怎么办？**  答：用 ​`\text{中文}` 包起来（LaTeX 正文不认直接输入的中文）。
4. **为什么** ​**​`a^10`​**​ **跟** ​**​`a^{10}`​** ​ **不一样？**  答：​`^`​ 只作用于紧跟的一个字符，​`a^10` = $a^10$；要整体作上标须用花括号 ​`a^{10}` = $a^{10}$。
5. **粘贴论文里的 LaTeX 不渲染怎么办？**  答：先确认 ​`$`​/​`$$` 成对；导入 Markdown 场景去 设置-编辑器-Markdown 语法 打开扩展语法开关。
