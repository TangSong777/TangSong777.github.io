# 嵌入式控制算法 PID 专项

> 教学讲义式专项文档：先讲 PID 原理与三个环节，再给**通用代码模板**，最后用两个嵌入式实例吃透——**风扇立棍（让棍立得稳）** 与**小车循迹/走直线（不让车歪）** 。能力基线：控制算法 PID L0 → 目标 L2（A 类·等级制）。前置：STM32 定时器/PWM（已学）。

## 一、PID 是什么

> PID（比例-积分-微分）是反馈控制算法：**测量当前值 → 与目标比较得误差 → 按"比例/积分/微分"计算输出 → 驱动执行器**，反复闭环让输出逼近目标。

- **类比（开车）** ：想让车速到 60：

  - 比例 P=看到差距踩油门（当前差多少就加多少）；
  - 积分 I=一直有差距就持续加力（消掉"差一点点"的静差）；
  - 微分 D=预测趋势提前收油（快到了就减速，防超调）。

## 二、三个环节逐个讲透

|环节|公式含义|作用|调大后果|
| --------| ----------| ----------------------------| -----------------------------------------|
|比例 P|`Kp × 误差`|即时响应，误差越大输出越大|过大→振荡；过小→响应慢|
|积分 I|`Ki × ∫误差dt`|消除稳态静差|过大→超调/震荡（I 风车）；过小→有静差|
|微分 D|`Kd × d误差/dt`|抑制变化趋势，提前刹车|过大→噪声放大、抖动；过小→超调|

- 误差 `e(k) = 目标 - 当前`；输出正负号决定执行方向。

## 三、离散化公式与两种写法

|写法|公式|适用|
| --------| ------| ------------------------------------|
|位置式|`u = Kp·e + Ki·Σe·T + Kd·(e-e_prev)/T`|直接给绝对输出（如占空比）|
|增量式|`Δu = Kp(e-e1) + Ki·e + Kd(e-2e1+e2)`|输出是"在上次基础上的增量"，防突变|

- `T`​ 为控制周期（如 1ms/5ms），积分就是累加 `e*T`​，微分就是相邻误差差 `(e-e_prev)/T`。

## 四、通用代码模板（可移植）

```c
typedef struct {
    float Kp, Ki, Kd;     // 参数
    float integral, prev_err; // 积分积累与上次误差
} PID;

void PID_Init(PID *p, float kp, float ki, float kd) { p->Kp=kp; p->Ki=ki; p->Kd=kd; p->integral=0; p->prev_err=0; }

float PID_Compute(PID *p, float setpoint, float measure, float dt){
    float err = setpoint - measure;
    p->integral += err * dt;                         // 积分：误差按时间累积
    float d = (err - p->prev_err) / dt;              // 微分：误差变化率
    float u = p->Kp*err + p->Ki*p->integral + p->Kd*d;
    if (u > max) u = max; if (u < -max) u = -max;    // 输出限幅保护
    p->prev_err = err;
    return u;
}
// 在定时器固定周期（如 5ms）中调用：out = PID_Compute(&pid, target, actual, 0.005f);
```

- **限幅必须**：防积分饱和与输出越界；积分可做"抗饱和"（输出饱和时冻结累加）。

## 五、实例一：风扇立棍（怎么立得稳）

> 目标：风扇气流托起/平衡一根轻杆，让杆接近竖直（角度 target=0），电机（风扇）转速是输出。这是个 **角度单环或 角度→角速度双环** 控制问题。

**物理直觉**：杆往左倒（角度大）→ 加大风扇（升力）把它推回；杆往右偏则减小。用**倾角传感器（MPU6050）** 测角度，PWM 控制风扇。

|控制量|测量量|执行器|
| --------------| ------------------------| -----------------------------|
|期望角度 0°|倾角（MPU6050 融合角）|风扇 PWM（ledc/PWM 占空比）|

**单环 P 起步（先稳再精）** ：

```c
// 每 5ms：err = 0 - angle（杆偏向一侧为负/正）
float out = PID_Compute(&pid, 0.0f, angle_deg, 0.005f);
set_fan_duty(center_duty + (int)out);   // 基速+修正；限幅防风扇过载
```

- 只用 P 就能大致回正，但会**来回轻微摆动（振荡）** ——加 D 抑制摆动：D 看到角度在快速变就往反方向提前用力；
- 若始终偏向一边（静差，如重心略偏）→ 加 I 消除。

**为什么"立得稳"三步调参**：

|步骤|做法|效果|
| ------| -----------------| ---------------------------------|
|1|Kp 从小到大|到"开始振荡"的临界值，取 0.6 倍|
|2|加 Kd 抑制振荡|摆动消失、回正快|
|3|有余差再加小 Ki|消除静差（够用即可，别大）|

**进阶：双环（内环角速度+外环角度）** ——风扇/杆响应快，先内环让角速度可控，外环再控角度，抗扰更强（无人机/自平衡车同思路）。

## 六、实例二：小车循迹与走直线（怎么不歪）

> 两个问题可统一到 PID：  
> **走直线** = 左右两轮速度一致 → 对每轮独立 PID 使"实际轮速=目标轮速"；  
> **循迹** = 用传感器偏差（灰度/线性CCD）算横向偏差 → PID 输出转向量加到左右轮（差速）。

|场景|设定值|测量|输出|
| ----------------| ------------------------| ------------------| ----------------------------|
|走直线(轮速环)|目标速度（如 30 cm/s）|编码器测实际轮速|该轮 PWM（两轮各一个 PID）|
|循迹(转向环)|偏差 0（居中线上）|灰度传感器偏差|左右轮差速（转向量 ±）|

**走直线（左右轮分别闭环）** ：

```c
PID pidL, pidR;
float errL = 30.0f - speedL;               // 目标-实际
pwmL = base + PID_Compute(&pidL, 30.0f, speedL, 0.005f);   // 左轮
pwmR = base + PID_Compute(&pidR, 30.0f, speedR, 0.005f);   // 右轮
```

- 不开环的原因：两轮电机特性/摩擦不同，给同样 PWM 也会跑偏；各自闭环后"轮速=目标"，就直了。

**循迹（偏差→差速）** ：

```c
float err = line_error;                             // 正中=0，偏左负/偏右正
float turn = PID_Compute(&linePID, 0.0f, err, 0.005f);
int left  = clamp(center - turn, 0, max_pwm);       // 转向：一加一减
int right = clamp(center + turn, 0, max_pwm);
```

- 循迹 P 太小跟不上弯，P 太大会甩尾震荡 → 加 D 提前抑制摆动；
- **为什么"走直线不歪歪扭扭"** ：核心是"车轮速度闭环 + 转向微小修正"，而非固定 PWM。

## 七、常见"立不稳/走不直"症状 → 调参表

|症状|原因|调节|
| -------------------| -----------------| -----------------------|
|来回大幅度振荡|P 过大|降 Kp（或加 Kd）|
|缓慢摆动停不下来|D 不足|加 Kd|
|始终偏一边/有静差|I 不够|加 Ki（克制小步加）|
|噪声大、电机抖|D 过大|降 Kd（或信号先滤波）|
|响应慢、懒洋洋|P 偏小|加 Kp|
|突然跳变输出|积分累积/未限幅|限幅 + 抗饱和|

## 八、参数整定方法

|方法|做法|
| --------------------| -----------------------------------------------------------------|
|试凑法（推荐起步）|Kp 从 0 慢慢加→临界振荡→×0.6；再加 Kd 抑振；最后小 Ki 消静差|
|Ziegler-Nichols|整定公式表（工程速成，从临界增益推导）|
|工程口诀|"先 P，后 I，再 D；P 定基调，I 消静差，D 压过冲"|

## 九、易错点与自测（附答案）

**易错**：控制周期 dt 固定且真实（用定时器，别用 delay+乱码）；单位不一致（角度用度、误差与输出同量纲）；输出忘记限幅；积分不重置导致"风车效应"；方向反了（输出极性错，一接就发散——先确认加输出是正反馈还是负反馈）。

1. **比例环节做得"多"、微分环节怎么做"快"？**  答：P 按当前误差大小给输出（"多"）；D 按误差变化趋势提前输出（"快"），抑制超调与摆动。
2. **为什么两个轮子要各自 PID 而不是给一样 PWM？**  答：电机/摩擦特性有差异，开环同样 PWM 会偏；各自闭环让轮速=目标，直线才直。
3. **立棍先调 P 到什么程度再加 D？**  答：P 加到"开始振荡"的临界再回退约 0.6 倍，然后加 D 压振荡，最后按需小 Ki 消静差。
4. **输出限幅为什么重要？**  答：防止输出超出执行器范围、防积分饱和；也保护电机/风扇不过载。
