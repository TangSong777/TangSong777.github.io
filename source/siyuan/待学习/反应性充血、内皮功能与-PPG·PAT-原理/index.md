# <span id="" style="display: none;"></span>反应性充血、内皮功能与 PPG·PAT 原理

> 学习文档定位：以"血管如何把一次心搏变成可测信号"为主线，讲清**反应性充血（PORH）** 、**内皮功能**、**PPG 原理**、**PAT 原理**，以及 **RHI** 的计算、正常值、影响因素与解释边界。每个知识点按"定义 → 类比 → 公式与参数表 → 实例 → 易错 → 验证"展开，附录给出 rPPG 工程实现。  
> 适用对象：非接触式手指视频（"一指知心"）研究，需要解释"PAT 增强而视频 G 通道脉动减弱"这类现象的读者。前置知识：无电路基础要求，只需知道心脏周期性泵血。

## 一、学习地图：本文要回答的六个问题

|问题|对应章节|
| --------------------------------------------| ----------|
|血压、血流、容积、张力有什么区别？|二|
|为什么管径是最强的流量杠杆？|二|
|内皮细胞到底在调节什么？|三|
|光强为什么随心跳波动？PPG 幅度代表什么？|四、五|
|EndoPAT 用手指气压测的是什么？RHI 怎么算？|六、八|
|为什么 RHI 不等于内皮功能？|九|
|为什么视频信号可能与 PAT 趋势相反？|十|

**先给结论（后文逐条展开）**

1. PPG 与 PAT 都不直接测血压、血流或内皮功能，它们测的是**血容量脉动的两种转换结果**（光学 / 机械气动）。
2. 脉搏幅度 $\Delta V$ 由**顺应性 × 血压脉动**决定，与平均血流量 $Q$ 不是一回事。
3. 反应性充血是"缺血—再灌注"引起的综合血管舒张，**NO 只是其中一条通路**。
4. RHI 是双侧校正后的 PAT 幅度比，**反映指端微血管的综合反应**，只能间接、部分地反映内皮功能。
5. 视频 G 通道幅度与 PAT 幅度之间隔着两套不同的传递函数，**趋势相反并不必然矛盾**。

## 二、最简单的血管模型：四个必须分清的生理量

> 先不考虑任何电子设备：把心脏看作周期性工作的水泵，把血管看作一套有弹性、能主动调节管径的输水管道。真实微循环还包含前毛细血管、动静脉吻合支，指端尤其富含动静脉吻合支。

|生理量|符号|它回答的问题|常用单位|
| ----------| ------| --------------------------| ----------|
|血压|$P$|血液对血管壁施加多大压力|mmHg|
|血流量|$Q$|每秒有多少血液流过|mL/s|
|血管容积|$V$|某段血管容纳多少血液|mL|
|血管张力|Tone|平滑肌收缩到什么程度|状态量|

### 2.1 血压提供动力，血流量由压差与阻力共同决定

收缩期射血、血压上升；舒张期血压下降，动脉压力呈周期性变化。对一段血管床，用类似欧姆定律的关系近似：

$$
Q=\frac{\Delta P}{R}
$$

|符号|含义|备注|
| ------| ----------------| ----------------------------|
|$\Delta P$|血管两端压力差|驱动项|
|$R$|血流阻力|主要由小动脉/微动脉贡献|
|$Q$|平均血流量|注意是"平均"，不含搏动分量|

### 2.2 管径是决定阻力的最强因素

理想圆柱管 + 稳定层流下，泊肃叶定律：

$$
R=\frac{8\eta L}{\pi r^{4}}\quad\Rightarrow\quad R\propto\frac{1}{r^{4}}
$$

|半径 $r$（相对基线）|相对阻力 $r^{-4}$|相对流量 $r^{4}$|
| -------------------| -----------| -----------|
|1.00|1.00|1.00|
|0.80|2.44|0.41|
|0.50|16.0|0.06|

**实例**：半径缩小 20%，阻力升到 2.44 倍、流量降到 41%；半径减半，阻力升到 16 倍。

> 易错：这是**理想圆管的教学模型**。真实血管有弹性、分支、神经调节和压力变化，不能直接用该公式预测人体 PORH 的血流倍数；它只证明"管径是最有效的流量杠杆"。

### 2.3 张力（Tone）是管径的控制量

平滑肌收缩程度（张力）→ 管径 → 阻力 → 流量。因此**一切改变平滑肌舒张/收缩的因素，最终都会改变血流量**：内皮释放的 NO、局部代谢物、交感神经都在这个链条上。

## 三、血管壁与内皮功能

### 3.1 三层结构

|层|位置|作用|
| ------------| ----------------| -----------------------------------------|
|血液|管腔内|携带氧气与代谢物|
|内皮细胞|血管内表面单层|感知剪切与化学刺激，分泌 NO、前列环素等|
|血管平滑肌|内皮外侧|收缩/舒张改变管径|

内皮不是被动保护膜，而是主动的调节器官。

### 3.2 剪切应力 → eNOS → NO → 舒张

血流加快时，血液对管壁的壁面剪切应力（shear stress）增大，内皮细胞感知后：

剪切应力 ↑ → 激活 eNOS（内皮型一氧化氮合酶）→ L-精氨酸生成 NO → NO 扩散入平滑肌 → 激活 sGC → cGMP ↑ → PKG → 平滑肌舒张 → 管径 ↑ → 阻力 ↓ → 血流 ↑

这是经典的**内皮依赖性血管舒张**。

### 3.3 边界：NO 不是唯一通路

腺苷、前列环素、内皮源性超极化因子、钾离子通道、局部代谢环境与神经调节都能舒张血管。**这条边界决定了后文"RHI 不能等同于内皮功能"的结论。**

### 3.4 "内皮功能受损"意味着什么

常见表现是 NO 生物利用度下降（氧化应激消耗 NO）、内皮依赖舒张减弱、促炎与促凝表型增强。这些改变常早于动脉粥样硬化斑块出现，因此被当作早期血管风险的指标。

## 四、顺应性与容积脉动

### 4.1 容积随每次心跳变化

收缩期管壁被撑开、舒张期弹性回缩，于是即使平均流量不变，容积仍随心跳周期变化：

$$
V(t)=\overline{V}+\Delta V(t)
$$

### 4.2 顺应性：血管有多容易被撑开

$$
C=\frac{dV}{dP_{\mathrm{tm}}}\qquad\Longrightarrow\qquad \Delta V_{\mathrm{pulse}}\approx C_{\mathrm{eff}}\,\Delta P_{\mathrm{pulse}}
$$

$P_{\mathrm{tm}}$ 为跨壁压（内外压差）。教学模型：$\Delta P$ 固定为 40。

|状态|$\Delta P$|$C$|$\Delta V$|
| ------------| ----| -----| ----|
|基线期|40|1.0|40|
|舒张后|40|1.5|60|
|顺应性下降|40|0.6|24|

### 4.3 两条必须记住的推论

- **脉搏幅度变大 ≠ 平均血流量变大；**
- **平均血流量变大 ≠ 脉搏幅度同比例变大。**

这两条是理解 PPG、PAT，以及"两类设备趋势不一致"的源头。

## 五、PPG 原理：用光观察血容量脉动

### 5.1 PPG 测什么、不测什么

PPG（Photoplethysmography，光电容积描记法）测量的是：光穿过或反射组织后，探测器接收到的**光强随时间的变化**。

|常见误解|实际含义|
| ----------------| --------------------------------------------------|
|"PPG 测血压"|不直接测；血压只能由波形形态间接推断|
|"PPG 测血流量"|不直接测；反映局部血容量脉动与光学性质变化|
|"PPG 测血氧"|脉搏血氧仪用双波长算 SpO₂，PPG 本身只提供容积波|

### 5.2 比尔–朗伯近似

血红蛋白吸收光、组织散射光；心搏使动脉及微血管床血容量变化，光路中的吸收随之变化：

$$
I(t)=I_0 e^{-\mu_a(t)L(t)}
$$

|符号|含义|
| ------| ------------------------------|
|$I_0$|入射光强|
|$I(t)$|探测光强|
|$\mu_a(t)$|等效吸收系数（随血容量变化）|
|$L(t)$|等效光程|

> 局限：真实组织存在多次散射，反射式 PPG 不能当成单路径透射模型。

### 5.3 AC、DC 与灌注指数

$$
I(t)=I_{DC}(t)+I_{AC}(t),\qquad \mathrm{PI}=\frac{I_{AC}}{I_{DC}}\times 100\%
$$

|成分|主要包含|
| ------| --------------------------------------------------------------------|
|AC|与心搏同步的动脉/微动脉血容量变化，也混有运动等动态光学因素|
|DC|组织背景、平均血容量、静脉血、非脉动动脉血、光源强度、慢变生理变化|

灌注指数 PI 是"相对幅度"，可抵消一部分光源强度与肤色差异；但它仍受接触压力与几何影响。

### 5.4 幅度传递函数

$$
A_{\mathrm{PPG}}\approx\left|\frac{\partial I}{\partial V}\right|\Delta V_{\mathrm{pulse}}
$$

PPG 幅度 = 光学灵敏度 × 容积脉动。光学灵敏度受波长、照明方向、组织厚度、散射、相机参数与 ROI 位置影响。

**波长选择的工程常识**：绿光（约 525 nm）在皮肤中穿透浅、对血红蛋白吸收敏感，是穿戴设备常用波段；红光/近红外穿透更深，适合透射式指夹。深色皮肤对绿光吸收更强，同条件下 AC 幅度更小。

### 5.5 一句话总结

PPG 是**光学转换后的容积波**，不是血流计。

## 六、PAT 原理：用气压感知指端容积

### 6.1 探头结构与双重作用

EndoPAT 探头：硬壳 + 可充气柔性气腔 + 气动压力传感 + 压力控制。手指伸入后气腔施加**反向压力**，典型设定为"舒张压 −10 mmHg 或 70 mmHg，取较低者"（部分设备提供固定 50 mmHg 模式）。

|作用|机制|
| ------------------| ------------------------------------------------------------------------------|
|防止静脉淤血|反向压力抑制远端静脉扩张，避免静脉 pooling 触发**静脉-小动脉反射**（venoarteriolar reflex）收缩|
|建立稳定力学边界|使指端搏动容积更稳定地转换成气压变化，并卸载部分动脉壁张力|

### 6.2 一次心跳的记录链

心搏 → 指端动脉血容量脉动 → 组织体积微变 → 挤压气腔 → 气压波动 → PAT 波形

$$
A_{\mathrm{PAT}}\approx K_{\mathrm{mech}}\,\Delta V_{\mathrm{finger,pulse}}
$$

|符号|含义|
| ------| ------------------------------|
|$A_{\mathrm{PAT}}$|PAT 脉搏幅度|
|$\Delta V_{\mathrm{finger,pulse}}$|指端与探头耦合的搏动容积变化|
|$K_{\mathrm{mech}}$|气腔/探头/组织的等效转换系数|

> 线性近似，不是厂商公开的完整标定公式。

### 6.3 EndoPAT 标准测量流程

|阶段|典型时长|操作要点|
| ------------| ------------| --------------------------------------------------------------------------------------|
|适应与静息|10–20 min|仰卧、安静、室温 21–24 ℃、避免说话与移动|
|基线记录|5 min|双手食指/中指戴探头，两侧同步记录|
|阻断|5 min|上臂袖带加压至 ≥收缩压 +60 mmHg，且 ≥200 mmHg（上限 300）；确认阻断侧 PAT 信号消失|
|放气后记录|5–6 min|快速放气，继续记录充血反应|

要点：**阻断侧与对照侧必须同时记录**；阻断时长与袖带位置需在研究内固定（前臂阻断与上臂阻断都可用，但不可混用）。

### 6.4 PPG 与 PAT 对比

|维度|PPG|PAT（EndoPAT）|
| -----------------------------| ----------------------------------| ----------------------------------------|
|使用什么物理手段|光吸收、散射、反射|气动压力与机械容积耦合|
|探头直接测量什么|光强变化|气腔压力变化|
|主要响应什么|受照组织内的血容量脉动及光学性质|指端的搏动容积变化|
|直接测血流/血压/NO/内皮功能|否（全部四项）|否（全部四项）|
|主要干扰因素|光照、肤色、光学几何、接触压力|探头压力、机械耦合、血管张力、交感活动|
|观测窗口|光所探测的组织体积（以浅层为主）|整个指端与气动探头耦合的容积|

**核心差别不在"精度"，而在观测窗口与传递函数不同。**

## 七、反应性充血：PORH 为什么发生

### 7.1 现象定义

PORH（Post-Occlusive Reactive Hyperemia）：袖带阻断动脉血流数分钟后突然放气，局部血流短时间内**超过基线**，随后回落。

### 7.2 三阶段

|阶段|血流状态|血管状态|信号表现|
| ------| ------------| --------------------| -----------------------------|
|基线|稳定|维持一定收缩张力|稳定的心搏脉动|
|阻断|远端接近零|远端小动脉逐渐舒张|脉搏幅度≈0（不是血管收缩）|
|放气|短暂超基线|阻力仍然较低|幅度可能升高|

### 7.3 缺血期发生了什么

1. 组织持续耗氧 → 氧分压下降；
2. 代谢物（腺苷、CO₂、H⁺、K⁺）蓄积；
3. 内皮与平滑肌多条舒张通路被激活；
4. 阻力血管舒张、阻力下降，但血流被袖带挡住。

> 易错：**阻断期没有脉搏 ≠ 血管收缩到最小。** 血管可能已经舒张，只是没有血流。

### 7.4 放气后为什么"超调"

上游压力恢复 + 远端阻力仍低 → 灌注压与低阻力的组合使血流冲高；随后代谢刺激消退、肌源性反应与自主神经调节把血流拉回基线。

> 注意：这里描述的是**平均血流量** **$Q$** 的曲线，不是 PAT/PPG 的幅度曲线。

## 八、RHI：把充血反应变成一个数

### 8.1 为什么要做双侧校正

放气后不仅测试手血流变化，血压、交感张力、室温等全身因素也在变。对照手提供"全身漂移"的参照：

$$
\mathrm{RHI}=\frac{(\text{阻断侧 放气后}/\text{基线})}{(\text{对照侧 放气后}/\text{基线})}\times\text{基线校正}
$$

### 8.2 参数量化（EndoPAT 类设备）

|参数|常见做法|
| ------------| ------------------------------------------------------------|
|放气后取窗|放气后 60–120 s，或 90–150 s（随软件版本与文献方案不同）|
|基线取窗|阻断前 2.5–3.5 min 的均值|
|校正|厂商专有的基线校正（baseline correction）|
|输出|RHI 与 LnRHI（自然对数）|

### 8.3 算例

|状态|测试手 PAT 幅度|对照手 PAT 幅度|
| -----------| -----------------| -----------------|
|基线|100|100|
|放气恢复|200|110|
|恢复/基线|2.0|1.1|

$$
R=\frac{2.0}{1.1}=1.82
$$

### 8.4 正常值与解读

|指标|判定|
| -------| ---------------------------------------------------|
|RHI|> 1.67 视为正常；≤ 1.67 提示血管内皮功能障碍风险|
|LnRHI|> 0.51 视为正常（与 1.67 等价换算）|
|分布|RHI 右偏，LnRHI 更接近正态，统计时通常用对数|

> 注意：1.67 是**风险分层阈值**，不是诊断金标准；单次结果不能替代临床诊断。

### 8.5 影响 RHI 的因素与测量规范

|类别|例子|处理|
| ----------| ---------------------------------------| ------------------------|
|测量条件|室温、光线、体位、静息时长、说话/移动|标准化并在记录中注明|
|短期行为|咖啡因、吸烟、进食、运动、睡眠不足|检查前禁食、禁烟数小时|
|药物|硝酸酯类、降压药、他汀|记录用药，研究内统一|
|生理|月经周期、年龄、性别、基础血管张力|分层分析或作为协变量|
|技术|探头压力、袖带位置、阻断时长、取窗|严格按方案执行|

## 九、RHI 能说明内皮功能吗：证据与边界

### 9.1 四步逻辑

|步骤|结论|确定性|
| ---------------------------| ---------------| --------------|
|缺血—再灌注引起血管舒张|存在|确定|
|内皮参与舒张调节|NO 是重要介质|确定|
|这些反应改变指端 PAT 幅度|可被连续记录|确定|
|由 PAT 响应推断内皮功能|间接关联|部分、非专一|

### 9.2 支持证据

- 抑制 NO 合成后，反应性充血幅度下降 → 该反应至少**部分**依赖内皮 NO 通路；
- 大型队列研究显示低 RHI 与心血管危险因素及事件相关 → 具备预后价值。

### 9.3 边界

5 分钟缺血后的充血涉及局部代谢物、钾通道、平滑肌舒张能力、微血管结构与交感活动。2019 年血管阻力研究方法指南明确指出：**不应把 5 分钟袖带阻断后的反应性充血视为内皮特异性检测**；相关综述也把 PAT 的充血反应描述为"仅部分依赖 NO"。

### 9.4 三个概念不要混用

|概念|含义|
| --------------| ------------------------------------------|
|PORH|缺血解除后局部血流暂时增加的生理现象|
|微血管反应性|微血管系统受刺激后改变阻力与灌注的能力|
|内皮功能|血管内皮调节舒缩、炎症、凝血等过程的能力|

### 9.5 与其他内皮功能检测的定位

|方法|测什么|优点|局限|
| -------------------| -----------------------| ----------------------------------| ------------------------|
|FMD（超声）|肱动脉直径变化|直接观察传导动脉|依赖操作者、标准化困难|
|RH-PAT（EndoPAT）|指端脉搏幅度比|操作者独立、自动分析、有预后证据|间接、仅部分依赖 NO|
|LSCI / 激光多普勒|皮肤微循环灌注|连续、有空间分辨|受运动与接触影响|
|血液标志物|NO 代谢物、黏附分子等|提供机制信息|有创、波动大|

## 十、从信号到指标：流量、容积与光学幅度的三层关系

### 10.1 三个变量

$$
\text{血流量 }Q\;\neq\;\text{脉动容积 }\Delta V\;\neq\;\text{光学幅度 }\Delta I
$$

恢复期 $Q$ 增加，不能推出 $\Delta V$ 增加，更不能推出 $\Delta I$ 增加。

### 10.2 两套传递函数

$$
A_{\mathrm{PAT}}\approx K_{\mathrm{mech}}\,\Delta V_{\mathrm{finger}},\qquad
A_{\mathrm{PPG}}\approx K_{\mathrm{optical}}\,\Delta V_{\mathrm{optical}}
$$

$K_{\mathrm{mech}}$ 与 $K_{\mathrm{optical}}$ 不同，且在实际条件下都会变化。

### 10.3 为什么"PAT 增强、视频 G 通道减弱"可能同时出现

|原因|机制|
| --------------| --------------------------------------------------|
|观测窗口不同|视频看浅层皮肤光学变化，PAT 看整个指端的容积响应|
|光学条件变化|平均血容量/散射改变 → $\partial I/\partial V$ 改变|
|接触约束不同|PAT 有气动反压，摄像头没有相同约束|
|采集参数|自动曝光、白平衡、压缩、ROI 漂移|
|信号提取|滤波带宽、去趋势、通道选择不同|

结论：这类"矛盾"应先排查**测量链**，再讨论生理。

### 10.4 先定目标，再定指标

|目标|推荐指标|
| ----------------------| ----------------------------------------|
|平均微循环灌注|DC、血红蛋白浓度、LSCI 血流指数|
|动脉脉动容积|PPG AC、PI，并与 PAT 幅度做相关|
|EndoPAT 式血管反应性|复现双侧流程，计算幅度比并做对照侧校正|

建议：把 PAT 当作**临床参考**，同时增加独立的灌注参考测量（如 LSCI），不要用 PAT 幅度直接当真实血流量。

## 十二、全篇自测（附答案）

1. 血压、血流量、容积、张力四者是什么关系？答：张力决定管径 → 管径决定阻力（$R\propto r^{-4}$）→ 阻力与压差共同决定流量 $Q=\Delta P/R$；容积是血管被压力撑开的结果。三者不能互换。
2. 为什么平均血流量增加，脉搏幅度不一定增加？答：$\Delta V\approx C_{\mathrm{eff}}\Delta P_{\mathrm{pulse}}$，幅度取决于顺应性与血压脉动；平均值与搏动分量是两个不同的量。
3. 阻断期 PPG 幅度接近零说明了什么？答：只说明血流被阻断、搏动消失；远端小动脉可能已经舒张。
4. RHI 为什么用双侧比值？答：抵消血压、交感张力、室温等全身性变化，使测试手的变化相对参考手可比。
5. RHI ≤ 1.67 就等于"内皮功能障碍"吗？答：不等于诊断。它是风险分层阈值；反应涉及多条通路，指南明确反对将其视为内皮特异性检测。
6. PAT 与 PPG 的核心差别是什么？答：物理转换不同（气动 vs 光学）、观测窗口不同（整个指端容积 vs 浅层光学体积），因此传递函数不同。
7. 为什么 PAT 恢复期增强而视频 G 通道减弱可能并不矛盾？答：$Q$、$\Delta V$、$\Delta I$ 处于三层不同位置；两套传递系数不同且在变化；此外还有采集参数与信号提取差异。
8. 若要让 MV-RHI 更接近 EndoPAT，最小改动是什么？答：固定双侧流程与取窗、标准化接触压力与光照、用相对基线的幅度比并做对照侧校正。

## 附录 A · 工程实现：从 PPG/rPPG 波形到心率

### A.1 生理频带与采样

|概念|值|说明|
| ----------| ---------------| ---------------------------|
|静息心率|60–100 bpm|主频约 1–1.67 Hz|
|生理频带|0.5–4 Hz|对应 30–240 bpm|
|采样率|视频 ≥ 30 Hz|低于 10 Hz 会丢失波形形态|

### A.2 模拟一段 PPG

```python
import numpy as np
fs = 100; t = np.arange(0, 10, 1/fs)
f = 72 / 60
ppg = np.sin(2*np.pi*f*t) + 0.3*np.cos(4*np.pi*f*t)
ppg += np.random.default_rng(0).normal(size=len(t)) * 0.2
```

### A.3 FFT 估心率

```python
fftv = np.fft.rfft(ppg); freqs = np.fft.rfftfreq(len(ppg), 1/fs)
mag = np.abs(fftv)
mask = (freqs >= 0.5) & (freqs <= 4.0)
idx = np.argmax(mag * mask)
print("心率 ≈", round(freqs[idx]*60, 1), "bpm")
```

### A.4 带通滤波

```python
from scipy import signal as sig
b, a = sig.butter(4, [0.5, 4.0], btype='bandpass', fs=fs)
clean = sig.filtfilt(b, a, ppg)
```

### A.5 从视频提取 rPPG

```python
import cv2, numpy as np
cap = cv2.VideoCapture("face.mp4"); x, y, w, h = 200, 100, 300, 300
sig = []
while True:
    ret, frame = cap.read()
    if not ret: break
    roi = frame[y:y+h, x:x+w]
    sig.append(roi[:, :, 1].mean())
sig = np.array(sig)
```

### A.6 评估与常见错误

|指标|含义|
| ----------------------| --------------------|
|主频是否落 0.5–4 Hz|估频是否可信|
|SNR|$10\log_{10}(\text{主峰功率}/\text{噪声带功率})$|
|与真值误差|< ±5 bpm 视为可用|

常见错误：采样率与信号不符、不滤波直接 FFT、ROI 选到背景、自动曝光导致整体漂移、把运动伪影当心跳、只做单通道平均而不做 ICA/PCA/POS 分解。
